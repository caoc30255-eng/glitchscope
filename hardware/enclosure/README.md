# v16 上下叠放外壳（现行打印版）

替换旧v5竖置外壳。7020在下、7010在上，两板保留原亚克力，STM32置于壳外；全打印面板，不使用PP片，不安装风扇。

## 从这里开始

- `assembly_guide.html`：2026-10-31交互装配指南，旋转、拆解、逐步查看螺钉与隔离柱连接。
- `preview_3d.html`：v16总装模型预览，浏览器直接打开。
- `print_instructions.txt`：完整尺寸、五金、装配与打印要求；保留原始试装口径。
- `stl/stage_1_frame/`：第一组内架，含孔径试片；每个STL代表一件，按文件名qty数量打印。
- `stl/stage_2_cover/`：第二组外罩，内架试配确认后使用。
- `print_manifest.json`：13种29个装机打印件，另有1个孔径试片，单位毫米、100%比例。
- `case_v16.scad`和`retained_mounts.scad`：可编辑OpenSCAD源文件；`export_stl.py`提供独立导出入口。

## 固定方式

7020原背面亚克力由边缘底托承托并用可移动压块定位，避让背面喇叭、焊脚及原螺钉。7010在原铜柱下接4根主体10mm隔离柱，再从安装梁下方锁紧。双通/公母及螺纹按原件试配。上层重量由4根独立支柱传到底托，不压在7020 PCB上。

尺寸来自直尺估测；接口外形和安装孔仍含示意参数，详见user_measurements.json与原始装配说明。CAD计算外形约186×180.4×115.2mm；装机打印件PETG全实心估算约233.6g，不含试片、支撑、板卡、原亚克力与五金，不是称重结果。实际打印耗材以店家切片为准。

已完成打印及装配。2026-11-02归档8张实拍图；实际装配反馈为打印件无修改、无顶碰、无松动，网线、电源及USB正常插拔。装配与人工配合检查记录见`../measured_enclosure_fit/README.md`。几何检查文件仍仅表示离线CAD检查。

英文文件名只做交付路径整理；14份STL与原v16打印包逐字节一致。旧v5已移到交付目录外备份，禁止混用。
