# 发行说明

## 当前发行内容 · 2026-11-02

本发行包含正式实板工作台、两块FPGA源码与固件、STM32 DUT工程、原生接收库源码、七项技能、复现入口、验证资料、v16外壳以及实物装配照片。

### 软件与功能

- 保留已验证的实验编排、记录额度、独立会话、停止与资源关闭机制。
- 接收策略页面支持动态N/64共同窗口局部参考，保留完整性检查、全64候选门槛和实际接收结果。
- 正式工作台版本清单与新SD成功session7绑定一致，包含新安装初始化、安装状态与设备访问锁适配。
- 模型冻结凭据、字节校验及原始实验状态保持可核对；展示摘要和原始证据分别保存。

### 工程与外壳

- 提供7010/7020构建入口、STM32构建入口及板端软件/原生库复现入口。
- v16采用7020下层、7010上层布局，保留原亚克力，附14种打印STL、数量清单、OpenSCAD源文件和交互装配指南。
- 归档8张原始实拍及实际装配反馈：打印件无修改、无顶碰无松动，网线、电源及USB正常插拔。
