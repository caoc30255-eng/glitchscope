# 匿名开源版本说明

本目录是供GitHub发布的独立公开副本，不替换原始评审工程、验收会话或历史日志。发布前按本次用户指定的身份关键词检查文件名、源码、注释、文档、隐藏属性、日志与二进制字符串；私有关键词表不随包分发。

## 公开整理范围

- 本地个人账户路径统一替换为中性工作目录前缀。涉及历史日志的文件明确作为公开投影，原件与原始哈希在私有资料中保留。
- STM32目录使用小写rte；启动文件、系统代码、RTL、位流、运行HEX、原生库和模型权重保持原字节。可选调试AXF不公开，可由源码重新构建。
- 协作记录公开26页PDF及匿名化案例；不附带可编辑原稿。大模型交互仍按原消息标识与来源关联，不把脱敏后的文件冒充原始字节。
- 移出完整演示图片、192个可恢复图片的原始接收包及相应图像缓存；算法和数值指标保留。新使用者上传自己的图片，或使用合成测试数据运行三项功能。
- 历史波形示例只保留CAP窗口绘图和表决所需的局部字节，其他位置为null；不以零填充值绘制未公开参考。64个ITEM的局部波形、原有评分和候选集合不变。它不包含可重建整图的完整原始帧。
- 设计报告仍为39页。图8改为同一已归档实测的像素错误数值卡；原先含演示图片的评审PDF保持在私有工程。部署章节改为直接使用本公开仓库，而非依赖历史私有ZIP。

`public_projection_manifest.json`列出原始哈希、公开派生文件和移出的工件。历史验收凭据内的哈希继续指向原始工件，不为公开投影重新制造历史验收；当前传输完整性使用`release_manifest.json`与工作台静态清单。

公开扫描摘要另移除了非必要的逐包哈希字段，保留会话、结果引用与全部统计值；原始逐包校验值仍由私有原件保存。

## 指南对应

依据本地AMD指南3.3自主选题，工程包含src、sim、build、board、data、skill、report及README目录映射；保留具体器件、工具版本、验证范围、性能与资源对比、七项技能、协作记录和从零复现说明。队伍资料、官方英文海报及最终演示视频按用户要求另行准备，不纳入源码目录。

本次公开整理验证软件契约和界面历史数据，不新增硬件试验，也不把本次软件检查当作新固件实板验收。现有约100MHz配置与150MHz独立失败记录继续分开。
