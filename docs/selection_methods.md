# 容错热力图：完整扫描与两种减少选点策略

## 产品定位

完整网格扫描提供逐格观测。规则选点和边缘AI选点作为两种并列的减少实测选点方法，面向有限预算内的边界探索与异常发现。操作者按任务选择方法；项目不以AI优于规则作为验收条件。

两种方法共享合法参数域、预算、真实执行器、反馈归档和三项判据，不由模型批准任务或扩大额度。模型域外拒答、回退及结束原因按原实现记录，不改算法以迎合评价表述。

## 比较基准和指标

主要参照是同条件、同重复次数的完整网格，分别报告：

- 实测独立格点数及其相对完整网格的减少比例。
- 实际硬件记录数和总上限，包含CONFIG、无扰动参照与重复测量。
- 观测覆盖率、边界触达、异常/混合结果及未测区域。
- 有完整参照时，已观测点与参照结果的对照；少量重复仍保留不稳定性。
- 实际耗时可按原件提供，但选点/记录减少不能直接推广为通用时间加速或同等全图质量。

少量选点产生的热力图应区分实测、未测和软件推断。需要完整实测地图时，选择完整网格；两种稀疏方法不以画出所有格子作为默认验收要求。

## 验收口径

1. 在声明参数域和预算内正确生成、执行与归档所选策略；参数和停止原因可追溯。
2. 规则和AI各自能完成选点执行/反馈链路；使用反馈时保存其输入前缀和决策来源。
3. 减少选点/记录的主张按可比完整网格基准计算，准备成本和重复次数不得漏算。
4. 如实呈现覆盖和边界结果，不把未测当成功、模型估计当实测、UNKNOWN当普通失败。
5. AI与规则之间的比较可作为描述性附加结果；不要求统计优势，不以一方必须胜出作为通过条件。

## 已有实测记录的示例解释

原冻结比较中，规则与AI各测4个独立格点、使用14条硬件记录；完整参照测14格、使用44条记录。两个稀疏策略各减少10个独立格点（约71.43%）和30条记录（约68.18%）。它们的格点覆盖率各为4/14，参照边界触达各为2/6；这些范围与减少比例同时保留。
