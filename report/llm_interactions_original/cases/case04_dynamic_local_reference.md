# 从全64块门禁到动态N/64局部参考

本文件为事后整理的案例导读，不是重写后的原始对话。原始消息编号可在独立评审记录包中定位。

## 问题

63个窗口可用、1个未对齐时，原规则只保留全64推荐门禁，导致可用数据无法给出参考。

## 操作者的作用

操作者先要求局部参考，再明确不能写死63块，其他有效数量也应支持。

## 模型与工具的迭代

保留完整64块候选的原规则，新增共同有效窗口排序；所有14组候选只比较同一组窗口及位数，不逐块选不同d/s。

## 结果

共同有效窗口1至64块均支持局部参考；0块或完整性/模型矛盾等异常不出候选。网页、报告及JSON/CSV显示覆盖率与未参与块，候选前置且字号放大。

## 结论边界

局部参考不覆盖未评估块，不等于整图最优或推荐配置的实板验证。
