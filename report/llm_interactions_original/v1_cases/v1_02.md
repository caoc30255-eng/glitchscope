# V1案例2 从控制UART仿真到双板字节回环

历史工作日期：2026-09-08 至 2026-09-10。这是事后来源整理，不补写原始聊天。

## 任务与问题

核心仿真通过之后，仍需要真实控制接口把PYNQ与AX7010连接。PHY收发、CRC和完整命令协议不是同一个层级，必须分别建立可观察的验证节点。

## 人工反馈与推进

9月8日缓存保留CRC测试输出片段；9月9日日志记载首次AX7010 Smoke Test只证明时钟、复位和LED心跳，完整控制协议尚未实测。9月10日再打通PYNQ、AXI UARTLite、物理连线、7010 Echo与返回链。

## 可恢复的原始片段

9月10日用户缓存原话含“TX 0x00 -> RX 0x00  PASS”，并列出0x55、0xAA、0xFF、0xA5和0x5A全部匹配，最后为“BYTE PATTERN TEST: PASS”。这些是缓存中的用户可见回传，仍保留其不完整性。

## 记录结果与范围

9月10日工程日志将该轮记为HW-UART-02双板PHY通过。它证明已测试位型的回环，不等于后续Parser、配置、START、结果邮箱和全部异常都在这一天完成。当前整理没有重跑串口。
