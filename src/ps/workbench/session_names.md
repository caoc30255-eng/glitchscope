# 会话名称与任务记录

每个真实任务有两个名称：

- 任务名称/会话别名：操作者填写，例如“现场扫描01”，可以包含中文；仅用于识别，不作为目录名。
- 实际会话编号：初始化时按原编号登记分配，例如session_00000050；不由浏览器猜测，不因别名改变。

初始化前显示“尚未分配”。分配后在底部悬浮进度栏、任务表、详细记录及原件目录的DEMO_UI/session_label.json显示对应关系。中断且未读到分配结果时显示待核对，不伪造一个编号。

原编号和UID不修改；失败后分配过的编号不重用。会话编号不是硬件试次数：初始化可能占用了一个编号却尚未发送记录，此时试次占用仍为0。

软件修复/波形分析显示“来源会话”，不创建新硬件会话，消耗0条。预览/模型查询显示“不创建硬件会话”。已有记录不会因为关闭本轮或更换界面而删除。

新账本的尝试、退役和会话绑定都可追溯到任务ID、父授权、计划SHA与代码版本。合成测试的PREVIEW记录不用于实测成绩，也不用于模型训练。
