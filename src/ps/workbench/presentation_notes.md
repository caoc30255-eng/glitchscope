# GLITCHSCOPE v1.1 字体与展示规范

## 官方资料与选择

2026-10-26联网查看官方资料后，采用以下组合：

|用途|字体|选择理由与来源|
|---|---|---|
|中文标题、导航、正文|Noto Sans SC 衍生子集，内部名称 Glitchscope CN|统一简体中文的字形与字重；[Google Fonts官方源文件与OFL](https://github.com/google/fonts/tree/main/ofl/notosanssc)|
|英文标题、数字、界面|Inter Variable|官方定位包含界面与标识，提供数字排版特性与可变字重；[Inter官方网站](https://rsms.me/inter/)|
|参数、SHA、证据详情、波形刻度|JetBrains Mono Regular|区分代码与参数内容，固定字符宽度；[JetBrains官方仓库](https://github.com/JetBrains/JetBrainsMono)|

同时查看了[MiSans官方资料](https://hyperos.mi.com/font/zh/faq/)，本包最终选择上述OFL字体组合，并保留对应许可文件。没有从第三方字体站下载二次打包字体。

## 本地字体

所有字体位于 `web/fonts/`，网页从自己的服务读取，不依赖Google字体CDN，也无需在操作系统安装。

中文字体由官方Noto Sans SC可变字体做字形子集，覆盖GB2312及界面用字，重新命名为Glitchscope CN。罕见字使用系统中文字体回退。原OFL与版权保留；Inter与JetBrains Mono二进制保持原样。来源URL、下载SHA256与子集说明保存在 `font_sources.json`。

## 字号层级

|层级|桌面尺寸|字重|
|---|---:|---:|
|总览展示标题|43–48px|690|
|工作区主标题|40px|740|
|侧栏导航|17px|580|
|区块标题|22px|680|
|正文|16px|400|
|表格、输入参数|15px|400–550|
|辅助说明|13–14px|400|
|英文眉题、次级来源标记|10–12px|500–650|

小屏幕按布局分级缩放，不再使用固定74px图标窄栏来挤压中文导航。重要按钮不依赖浅灰文字。波形使用独立深色展示区，刻度保留等宽字体；窄屏可以横向浏览波形，避免缩成无法阅读的小字。

## 工作区结构

- 三个核心入口：容错热力图、图片传输与修复、接收策略与波形。
- 边缘AI并入容错热力图，在顺序、规则细化、边缘AI三种策略中选择；旧 `#ai` 链接兼容转到此工作区。
- 接收策略页原生挂载64块矩阵、候选参数、三轨迹及逐位表决，不嵌入另一套报告页面。
- 独立报告继续用于交付与导出，和工作台内的原生视图使用相同分析数据。
- 保留专注展示模式；不改变底层试验、修复或AI模型，也不改变历史数据来源。
