# 移植与错误定位

CSV列必须严格为case,cycle和spec.signals列出的信号，顺序一致。case从0递增，每个case的cycle从0连续递增。信号位宽1–64，值用十进制或0x十六进制；X/Z不被默默转成0。

1. 明确激励在下降沿还是上升沿前驱动，输出在哪个delta/延时后采样。复位高低电平和同步/异步语义不能从端口名推断。
2. 比较第一处分歧：输入向量/时钟对齐→复位→使能→valid→数据/错误标志→内部累加器或状态。不要先大面积修改RTL。
3. 保持值也是协议：valid=0的周期如要求data保持，就必须比较，不能把该周期全部跳过。
4. 对含NCO/相位状态的模块，case可以枚举初态。初态枚举是仿真假设，不代表读到了实际初态。
5. 保留失败向量和旧版本，再新增针对性回归。若发现参考模型错误，解释来源、独立修正并重跑，不能静默改答案。

失败来源：本项目曾遇到仿真工具已编译却未真正运行、局部波形因初相不确定而存在多解、停止位与禁用毛刺路径需要独立排除。历史1125例日志证明有限数字对照；不证明模拟电气完整性、150MHz时序签核或所有未知输入。

移植时替换RTL、测试台、参考生成器及spec，比较器可保留。新增测试台应报告自身精确用例与周期数，不能复用本项目1125计数。

实际轨迹应在仿真结束并冻结后比较，避免比较过程中仍有其他进程追加或改写CSV。SHA在本工具是工件一致性记录，不是抗恶意篡改签名。
